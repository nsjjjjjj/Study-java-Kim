# Study Java Kim

김영한 Java 강의를 따라가며 작성한 Java 문법 및 객체지향 실습 코드 모음입니다.

## 학습 범위

- `Object` 클래스와 `toString`, `equals`
- 불변 객체와 참조 공유 문제
- `String`, `StringBuilder`
- 메서드 체이닝
- 간단한 객체지향 예제

## 폴더 구성

```text
src/
├── lang/object
├── lang/immutable
└── lang/string
```

## 실행 방법

각 예제는 독립적인 `main` 메서드를 가진 Java 파일로 구성되어 있습니다. IntelliJ IDEA에서 원하는 `Main` 클래스를 선택해 실행하면 됩니다.

## 저장소 성격

완성된 애플리케이션이라기보다 Java 기본기 학습 과정을 기록한 저장소입니다. 포트폴리오 프로젝트보다는 학습 로그에 가깝습니다.
